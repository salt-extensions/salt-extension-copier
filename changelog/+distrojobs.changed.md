Reworked the CI test jobs to respect the new `linux_test_distros` and `*_releases` answers. The `Linux` job keeps its name (so existing required status checks continue to work), corresponds to the `Ubuntu` distribution selection and runs on the selected Ubuntu releases. Non-Ubuntu Linux distributions are tested inside VMs with a parametrized Salt/Python version matrix, whose Python versions are provisioned by `uv` – except Alpine, which runs against the OS-packaged Salt release like the BSDs since important binary dependencies lack `musl` wheels. The VM tooling (`uv`, `nox`) is installed from PyPI at the pinned versions tracked in the template, making test environments predictable and refreshing cached VM images on version bumps. Artifact and CodeCov upload names now consistently reference the job name and include the OS release where applicable.
