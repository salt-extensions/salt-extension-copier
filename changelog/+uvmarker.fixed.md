Restricted the pinned `uv` in the `nox` pre-commit hooks' `additional_dependencies` to platforms with `uv` wheels via an environment marker. On other platforms, e.g. FreeBSD, the hooks previously failed to install since building `uv` from source requires a Rust toolchain. `nox` now falls back to the `virtualenv` backend there (or still uses `uv` when it's available on `PATH`).
