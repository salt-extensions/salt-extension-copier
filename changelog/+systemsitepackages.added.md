Added support for inheriting system-wide packages in the development and {tool}`nox` session virtual environments by setting {envvar}`VENV_SYSTEM_SITE_PACKAGES=1 <VENV_SYSTEM_SITE_PACKAGES>`, easing development of OS-specific extensions whose dependencies are only available as system packages. This mode falls back to `venv` and `pip` since `uv pip install` ignores inherited packages.
