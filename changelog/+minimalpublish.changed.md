Following PyPI's recommendation of minimal Trusted Publisher workflows, {path}`deploy-package-action.yml <.github/workflows/deploy-package-action.yml>` was reduced to artifact verification and publishing: its publish jobs republish the exact verified bytes with minimal permissions. The GitHub release and docs deployment moved to a new {path}`finalize-release-action.yml <.github/workflows/finalize-release-action.yml>` workflow outside the publishing trust boundary.
