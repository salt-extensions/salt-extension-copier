Added dependency caching to the CI workflows. The pre-commit environments and uv's wheel cache are now persisted between runs on GitHub-hosted runners, keyed on the pre-commit configuration and the Salt/Python/OS release matrix entry respectively. Release builds never use caches, enforced both by an explicit `use-caches: false` input in the release workflows and a tag ref check in the cache steps. A new `Clear Actions Caches` workflow allows purging all caches or a single key via manual dispatch.
