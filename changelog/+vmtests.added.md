Added CI test jobs for FreeBSD and OpenBSD when selected in `os_support`. Since there are no native GitHub-hosted runners for these platforms, the tests run inside VMs on Linux runners, courtesy of the `vmactions` project. There are no Salt onedir builds for these platforms either, so instead of a Salt version matrix, the tests run against the Salt release packaged by the OS, with the project's minimum Salt requirement acting as a lower bound.
