Added a new `typing` question, which generates support for static type checking via `ty`. When enabled, the project receives a pre-commit hook typechecking the complete project, corresponding `[tool.ty.*]` configuration in `pyproject.toml` and a `utils/_types.py` module providing type aliases for common Salt loader globals. The generated loader module stubs declare the dunders they use inside `typing.TYPE_CHECKING` blocks.
